# Dokime Feature Drop

## Why

The agreed 49-item drop fixes slow native delivery, runtime persistence, shutdown, report fidelity and inconsistent operator workflows. Existing implementation slices and unfinished edits must be completed together without losing their work.

## What Changes

- Native path-based plugin/report delivery, bounded transfer sizes and operation deadlines.
- Shared live/report presentation, execution controls and prompts, destination selection, responsive settings and branding.
- Event-driven GUI data flow, batched runtime persistence and telemetry, deterministic shutdown and performance benchmarks.
- File watcher readiness, rotation segments, deterministic selection and bounded source waiting, with immediate unavailable FTP-root failure.
- The complete numbered inventory is in tasks.md; no item is waived by an individual slice completing.

## Capabilities

### New Capabilities

- `feature-drop`: coherent operator workflows, bounded native delivery and observable performance.

### Modified Capabilities

- Existing execution, evidence, plotting, settings and desktop behavior are updated together.

## Impact

Domain and runtime operations, server handlers, native desktop bridge, React views, generated Rust/Python/TypeScript client surfaces, package profiles, benchmarks, tests, README and branding assets. Harmos publication and the separate remote-streamline release gate final dependency pins and review into dev.

## Organization Packs (absorbed)

## Why

Split out of the 2026-10-21 feature drop by user scope decision; the drop ships items 1-49 and its consolidation.

## What Changes

- Organization Packs replace branding packs and own appearance plus organizational update defaults, named connections and plugin release sources. App updates support direct manifests, GitHub Releases and GitLab Releases through one resolved policy; installation remains explicit.

## Capabilities

### New Capabilities

- `organization-packs`: organization appearance and update defaults, trusted app/plugin release sources.

### Modified Capabilities

- None.

## Impact

Authored assets and Python branding generator; GUI native app/branding.rs and gitlab.rs, startup and command catalog; desktop branding/update adapters and Settings; domain plugin metadata, runtime install/consent/restart and release asset manifests; build/package paths, examples, README and generated guidance.
