# Organization Pack Coverage Tasks

## 1. Contract

- [ ] 1.1 Lock the source inventory from the findings: each operator-facing occurrence with its file, grouped by the fix it shares.

## 2. Operator Surfaces

- [ ] 2.1 Produce the initial desktop and report title and icon from the resolved or captured appearance; replace the fallback report title.
- [ ] 2.2 Read the label for the traceability version row, plugin compatibility text and file picker filters.
- [ ] 2.3 Derive suggested diagnostics, support bundle, secrets and log file names from the distribution identifier, changing writers and readers together.
- [ ] 2.4 Pass the resolved label into operator-facing error and status messages, with the distribution default before the pack loads.
- [ ] 2.5 Set the product name in report data from the captured appearance and issue new remote access certificates under the label.

## 3. Fixed Packaged Pack

- [ ] 3.1 Make a pack supplied at packaging replace the bundled default and mark the installation as fixed.
- [ ] 3.2 Hide pack import, change and removal in a fixed installation and ignore a pack in its application folder.

## 4. Final Validation

- [ ] 4.1 Run focused desktop, report and packaging tests for a fixed pack, an imported pack and no pack; update the product guide's organization section.

## Workflow Follow-Up

- Executable and process names are out of scope by decision.
- Delivery uses targeted validation and merges to dev without waiting for CI; breakage is fixed in follow-ups.
