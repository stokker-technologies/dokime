# Dokime Protocol Contracts

The authoritative tree has model/v1 (exchanged values), host/v1 (host operations)
and plugin/v1 (host-invoked plugin operations). One file owns each resource's
service, operation sections, requests, responses and values. Nested resources use
subfolders. There is no client or plugin/host protocol directory.

Every host RPC declares harmos.model.v1.callers as CLIENTS, PLUGINS or ALL.
Product plugin executor methods also record CLIENTS for their host transport client,
with host-only Protected admission and no application client/context projection. Visibility, grants and trusted scope remain separate
admission checks. Storage operations are native and in-process, never wire twins.

Run `mise run generate -- --protocol` to regenerate the protocol crate and four
SDK projections. Python wire modules and C# requests/stubs are internal; public
SDK barrels omit versions. C++ wire messages/stubs are generated by CMake.
Run `mise run format` and `mise run check -- --repository` for Buf formatting,
lint, mandatory callers, repository/workflow checks. A second generation must
leave committed output unchanged.

[Execution Host](../docs/execution-host.md#final-library-definition-contract)
contains the complete identity/caller/type mapping and consumer work lists.
[Architecture](../docs/architecture.md#final-library-assembly-and-storage-contract)
owns assembly, narrowing, backend methods and the query merge. Definition proof
does not establish consumer compilation or runtime behavior. Development schemas
remain at baseline v1; incompatible storage is refused, never reset implicitly.

The complete proto/harmos tree is vendored unchanged from the Cargo revision.
Refresh it as one input when pinning, not as a local library fork. Tooling is owned
by this repository; it never executes the dependency's generators.
