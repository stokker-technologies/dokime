# Dokime Protocol Contracts

The authoritative tree has model/v1 (exchanged values), host/v1 (host operations)
and plugin/v1 (host-invoked plugin operations). One file owns each resource's
service, paired requests and responses, and resource values. The fixed sections are
Imports, Options, Services, Requests and Responses, Resources and Enums, including
empty sections. Nested resources use
subfolders. There is no client or plugin/host protocol directory.

Product wrappers expose only client-used library host operations. They declare
their own services and explicit CLIENTS audience and reuse the library's unchanged
request/response messages. No library host gRPC service is composed onto the wire.
Plugin Time, Invocations, Operations and own-settings facilities use the library's
plugin protocol identities. Generator projections derive from the embedded
descriptors and declared audiences; there is no composition file.

Every host RPC declares harmos.model.v1.callers as CLIENTS, PLUGINS or ALL.
Product plugin executor methods omit the callers option: their Protected bindings
are host-only and have no application client/context projection. Visibility, grants and trusted scope remain separate
admission checks. Storage operations are native and in-process, never wire twins.

The Rust crate keeps generated packages private and exposes the complete host,
model and plugin contract surfaces. Hand-written model construction and validation
live under `src/model/`; plugin envelope validation lives under `src/plugin/`,
with the plot authoring value in `src/builders.rs`. Its separate value avoids
collisions with Prost-generated getters and exposes its message explicitly.

Run `mise run generate -- --protocol` to regenerate the protocol crate and four
SDK projections. Python wire modules and C# requests/stubs are internal; public
SDK barrels omit versions. C++ wire messages/stubs are generated by CMake.
Run `mise run format` and `mise run check -- --repository` for Buf formatting,
lint, mandatory callers, repository/workflow checks. A second generation must
leave committed output unchanged. `mise run check:generated` compiles each SDK
surface independently; its Python story consumes the current wheel built by
`mise run build:python` and installed by `mise -C sdk/python run install`.

[Execution Host](../docs/guides/execution-host.md#final-library-definition-contract)
contains the complete identity/caller/type mapping and consumer work lists.
[Architecture](../docs/project/architecture.md#final-library-assembly-and-storage-contract)
owns assembly, admission, backend methods and the query merge. Definition proof
does not establish consumer compilation or runtime behavior. Development schemas
remain at baseline v1; incompatible storage is refused, never reset implicitly.

The complete proto/harmos tree is vendored unchanged from the Cargo revision.
Refresh it as one input when pinning, not as a local library fork. Tooling is owned
by this repository; it never executes the dependency's generators.
